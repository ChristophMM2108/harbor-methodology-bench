# SDD Tasks

1. Read spec, plan, constitution, and relevant design artifacts.
2. Create coherent vertical or architectural slices.
3. Keep tasks small enough to execute without losing context.
4. Add explicit dependencies.
5. Reference requirement and acceptance-criteria IDs.
6. Include files/areas, implementation intent, and verification.
7. Make migrations, tests, and risky work explicit.
8. Add a final verification task covering all acceptance criteria.
9. Produce a dependency graph.
