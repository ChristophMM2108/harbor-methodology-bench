# Working agreement

This repository follows a three-step working agreement. Follow it for any change
that touches more than one file or takes more than two steps.

1. **Plan before editing.** Write a numbered plan to `PLAN.md` — one line per
   step, each step independently checkable. Do this before the first edit.
2. **Verify each step.** After each step, run the project's own tests or the
   smallest command that proves the step. Do not batch verification to the end.
3. **Close out.** Before finishing, restate each plan step and the evidence that
   it holds. If a step is unproven, say so rather than implying it passed.

Use the `demo-checklist` skill when the work has more than two steps.
