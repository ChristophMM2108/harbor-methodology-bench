## Spec-Driven Development

This repository uses the SDD Agent Kit.

For substantial changes, use:

`specify → clarify → plan → tasks → analyze → implement → verify`

Canonical SDD locations:
- Constitution: `docs/sdd/constitution.md`
- Specifications: `docs/sdd/specs/`
- Codex Skills: `.agents/skills/`
- Kit manifest: `.sdd-kit/manifest.md`

Use the `sdd-*` Skills for substantial feature development. Do not silently change requirements during implementation. If requirements change, update the specification explicitly.

See `.sdd-kit/manifest.md` for the installed kit version and entry points.
